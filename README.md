# AI Voice Agent Portfolio Website

A simple Next.js starter for an AI Voice Agent Developer / Automation Specialist website.

## Pages / Sections included
- Hero
- Services
- Tools
- Projects
- FAQ
- Contact

## How to run
1. Open the project folder in your terminal.
2. Install dependencies:
   npm install
3. Start development server:
   npm run dev
4. Open:
   http://localhost:3000

## What to customize first
- Replace "Emmanuel" in `app/layout.tsx`
- Update project examples in `app/page.tsx`
- Change contact form to Formspree, Resend, EmailJS, or your own API route
- Add your Loom demos, screenshots, and testimonials
- Connect your domain and deploy to Vercel
